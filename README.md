# Кругозор

PWA для iPhone с подборкой качественных статей для расширения кругозора. Читать статьи можно прямо в приложении, английские слова переводятся по тапу, а по любой теме можно поговорить с Claude.

## Что умеет

- **Лента статей по 13 темам**: физика и математика, космос, биология, медицина, история и археология, технологии и общество, психология и нейронаука, экономика, культура и искусство, природа и экология, философия, география, «необычное в обычном».
  - Источники — серьёзные издания на русском и английском: Quanta, Aeon, Nautilus, Smithsonian, BBC Future, Knowable, N+1, Naked Science, ПостНаука, Arzamas, «Кот Шрёдингера», «Элементы» и другие.
  - У каждой статьи есть тема, теги, краткое описание по-русски, дата, время чтения и язык.
  - Ленту можно фильтровать по теме, тегу и языку, показывать только непрочитанное и искать по ней.
- **Свежие статьи приходят сами**:
  - раз в сутки GitHub Action просит Claude найти новые статьи через веб-поиск и дописывает их в общую ленту;
  - в приложении кнопка ↻ проверяет общую ленту или запускает поиск свежих статей по выбранным темам;
  - если общая лента давно не обновлялась, приложение раз в сутки само ищет свежие статьи при запуске.
- **Статьи по запросу**:
  - напишите в чате ✨ «хочу больше статей про эффективность тренировок» — Claude запустит поиск, а найденные статьи сразу попадут в ленту (фильтр «🔎 Мои запросы»);
  - то же самое можно сделать в окне ↻ → «Статьи по запросу».
- **Случайное**: «Мне повезёт» показывает одну статью, ниже подборка из пяти статей разных тем, кнопки «Случайная тема» и «Удиви меня».
- **Режим чтения**: текст статьи открывается внутри приложения; можно менять размер шрифта, читать офлайн то, что уже открывали, и добавлять статьи в избранное.
- **Перевод**:
  - тап по английскому слову показывает перевод на русский со словарными вариантами и озвучкой;
  - выделенная фраза переводится целиком;
  - кнопка «✨ В контексте» спрашивает Claude, что слово значит именно в этом предложении.
- **Claude**: кнопка ✨ у каждой статьи открывает окно разговора. Готовые вопросы: «объясни простыми словами», «какой контекст», «спорные моменты», «что почитать дальше». Claude может искать в интернете и открывать статью по ссылке. История разговоров сохраняется на устройстве.

## Как установить на iPhone

1. **Включите GitHub Pages**: Settings → Pages → Build and deployment → Source: **GitHub Actions**. Без этого шага сайт не публикуется: workflow покажет предупреждение «Сайт не опубликован».
2. **Запустите публикацию**: Actions → «Лента и публикация» → Run workflow. Публикация также запускается при каждом пуше в ветку по умолчанию.
3. **Откройте сайт** в Safari на iPhone: `https://skjat.github.io/Translate/`.
4. **Установите приложение**: «Поделиться» → «На экран „Домой“».
5. **Подключите Claude**: в приложении откройте «Настройки» → «API-ключ» и вставьте ключ с [platform.claude.com](https://platform.claude.com/) → API Keys. Ключ хранится только на телефоне и уходит напрямую в `api.anthropic.com`.
   - Лучше завести отдельный ключ с лимитом расходов.

### Ежедневное обновление общей ленты

1. Добавьте секрет: Settings → Secrets and variables → Actions → New repository secret → `ANTHROPIC_API_KEY`.
2. Необязательные переменные (вкладка Variables того же раздела):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `CLAUDE_MODEL` | `claude-opus-5-5` | Модель для поиска; `claude-sonnet-5-5` примерно вдвое дешевле |
| `ARTICLES_PER_RUN` | `10` | Сколько статей искать за запуск |
| `TOPICS_PER_RUN` | `5` | Сколько тем за запуск; берутся темы, где дольше всего не было свежих статей |

- Расписание — каждый день в 07:23 по Москве; его можно поменять в `.github/workflows/pages.yml`.
- При ручном запуске (Run workflow) можно указать запрос, например «эффективность тренировок».
- Без секрета лента не обновляется (workflow покажет предупреждение «Лента не обновлена»): сайт публикуется как обычно, а свежие статьи приложение ищет само раз в сутки, если в его настройках есть ключ Claude.

## Сколько это стоит

| Действие | Примерная стоимость |
|---|---|
| Поиск 8–10 свежих статей (Opus 5.5) | $0.3–1 |
| Ответ в чате | центы |
| Перевод «в контексте» | доли цента |
| Перевод через Google или MyMemory | бесплатно |

- Веб-поиск стоит $10 за 1000 запросов, сверх токенов.
- После каждого поиска приложение показывает примерную стоимость.
- Дешевле всего выбрать Sonnet 5.5 или Haiku 5.5 в настройках.
- Автопоиск в приложении не дублирует GitHub Action: он запускается, только если общая лента не обновлялась больше 30 часов.

## Как это устроено

Статический сайт без сборки: HTML, CSS и ES-модули.

| Файл | Назначение |
|---|---|
| `index.html`, `css/app.css` | Интерфейс, светлая и тёмная темы |
| `js/app.js` | Вкладки: лента, случайное, моё, настройки |
| `js/discover-core.js` | Поиск статей через Claude (общий для браузера и GitHub Action) |
| `js/discover.js` | Обновление ленты в приложении и автопоиск |
| `js/chat.js` | Окно разговора с Claude и инструмент `find_articles` |
| `js/reader.js` | Режим чтения |
| `js/translate.js` | Перевод по тапу и выделению |
| `js/claude-core.js`, `js/claude.js` | Параметры запросов, модели, обработка ошибок |
| `js/store.js`, `js/db.js` | Хранение настроек, ленты, избранного и чатов (localStorage и IndexedDB) |
| `data/articles.json` | Общая лента |
| `scripts/refresh-articles.mjs` | Скрипт, который запускает GitHub Action |
| `sw.js` | Офлайн-работа |
| `vendor/anthropic-sdk.js` | Официальный `@anthropic-ai/sdk`, собранный для браузера |

**Защита от выдуманных ссылок.** Claude отправляет подборку через инструмент `submit_articles`. Приложение пропускает в ленту только статьи, чей URL реально встречался в результатах веб-поиска. Дубликаты и статьи без темы или описания отсеиваются.

**Внешние сервисы:**

| Сервис | Для чего | Где поменять |
|---|---|---|
| [Jina Reader](https://jina.ai/reader) (`r.jina.ai`) | Извлечение текста статьи | Настройки → Чтение → Дополнительно (там же необязательный бесплатный ключ Jina — без него Jina иногда ограничивает анонимные запросы) |
| `translate.googleapis.com` | Перевод слов | Настройки → Перевод |
| MyMemory | Запасной переводчик | Настройки → Перевод |

Некоторые сайты (например, N+1, Undark, Econs) защищены от автоматического чтения: их текст в приложение не загрузить. Для таких статей ридер сразу предлагает открыть оригинал в Safari или пересказ от Claude и запоминает сайт, чтобы не ждать впустую в следующий раз.

`translate.googleapis.com` — неофициальный бесплатный эндпоинт: если он перестанет отвечать, приложение само переключится на MyMemory.

## Локальная разработка

```bash
npm install
```

```bash
npm run serve
```

Приложение откроется на http://localhost:8080/.

```bash
npm run check
```

Проверяет формат `data/articles.json`.

```bash
ANTHROPIC_API_KEY=sk-ant-... npm run refresh
```

Ищет свежие статьи и дописывает их в `data/articles.json`.

```bash
npm run vendor
```

Пересобирает `vendor/anthropic-sdk.js` после обновления SDK.

После изменения файлов приложения увеличьте `VERSION` в `sw.js`, чтобы установленное приложение быстрее получило обновление.
